# Arquivo de Investigações

Quadro de investigação (post-its, fotos, PDFs, fitas, pinos, vários quadros num arquivo) como aplicativo Android.

## Baixar e instalar

**Link direto da versão mais nova:** https://github.com/Slashovisk/Quadro-/releases/latest/download/Arquivo-de-Investigacoes.apk

Abra o link no celular ou tablet, baixe e toque no arquivo. Na primeira vez, o Android pede para permitir "instalar de fontes desconhecidas"; se o Play Protect avisar, toque em **Instalar mesmo assim**.

## Atualizações

O app **se atualiza sozinho**: toda vez que abre (com internet), busca a página mais nova deste repositório (`web/index.html`) e passa a usá-la, sem baixar APK novo. Os quadros ficam guardados no aparelho e não se perdem. O APK só precisa ser reinstalado se mudar a parte Android (pasta `app/`); cada envio ao repositório também gera um APK novo em **Releases**.

## Para quem edita

- `web/index.html`: o aplicativo inteiro (uma página só).
- `app/`: a casca Android (WebView).
